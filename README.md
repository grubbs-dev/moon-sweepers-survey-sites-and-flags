# Survey Sites and Flags 0.1.4

Shows every flag and survey site on the station Moon Map, including locations that have not yet been discovered.

## Installation

1. Install BepInEx 6 IL2CPP and the Moon Sweepers mod loader required by the game.
2. Extract this archive into the folder containing `MoonSweepers.exe`.
3. Confirm the DLL is at `BepInEx/plugins/SurveySitesAndFlags/SurveySitesAndFlags.dll`.
4. Open the orange station console and press `E` for Moon Map.

Undiscovered locations are gray. Untangled flags and surveyed sites are green.

## Requirements

- Moon Sweepers 1.0.5, Windows x64
- BepInEx 6 IL2CPP win-x64
- Moon Sweepers mod loader/bootstrap used by the game setup

## Uninstall

Remove `BepInEx/plugins/SurveySitesAndFlags`.
